# mcgl-mcp

[![npm](https://img.shields.io/npm/v/mcgl-mcp)](https://www.npmjs.com/package/mcgl-mcp)
[![CI](https://github.com/exi66/mcgl-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/exi66/mcgl-mcp/actions/workflows/ci.yml)

MCP-сервер для [форума Minecraft Galaxy](https://forum.minecraft-galaxy.ru/main/). Подключается к Claude, Cursor и другим AI-ассистентам и даёт им читать форум: разделы, темы, посты, опросы.

Что можно попросить у ассистента:

- «Что нового на форуме MCGL?»
- «Перескажи последние сообщения в теме про Гран-при амфибий»
- «О чём спорят в разделе Предложения?»
- «Найди в теме 133931 рецепт крафта и объясни его»

## Установка

Нужен [Node.js](https://nodejs.org) 22 или новее. Отдельно ставить ничего не надо: клиент сам скачает и запустит сервер через `npx`.

**Claude Code:**

```bash
claude mcp add mcgl -- npx -y mcgl-mcp
```

**Claude Desktop, Cursor и другие:** добавьте в конфиг MCP-серверов (`claude_desktop_config.json`, `.cursor/mcp.json` и т.п.):

```json
{
  "mcpServers": {
    "mcgl": {
      "command": "npx",
      "args": ["-y", "mcgl-mcp"]
    }
  }
}
```

На Windows, если клиент не находит `npx`: `"command": "cmd"`, `"args": ["/c", "npx", "-y", "mcgl-mcp"]`.

### Вход под своим аккаунтом (необязательно)

Без входа доступно чтение форума, сообществ и скриншотов. С входом — форумы сообществ, вступление и выход, профили игроков и публикация от вашего имени (ассистент всегда спрашивает подтверждение перед отправкой).

```bash
claude mcp add mcgl -e FORUM_LOGIN=ник -e FORUM_PASSWORD=пароль -- npx -y mcgl-mcp
```

В JSON-конфиге то же самое задаётся через `"env": { "FORUM_LOGIN": "ник", "FORUM_PASSWORD": "пароль" }`.

Пароль хранится только в конфиге клиента на вашем компьютере и отправляется только на форум. Если войти не получилось, текст ошибки форума виден в логах MCP-сервера в клиенте. У форума есть лимит попыток входа, поэтому после неудачи сервер больше не пытается войти: исправьте пароль и перезапустите клиент.

## Инструменты

| Инструмент                  | Что делает                                                                                                |
| --------------------------- | --------------------------------------------------------------------------------------------------------- |
| `forum_list_sections`       | разделы форума по категориям                                                                              |
| `forum_latest_topics`       | темы со свежими сообщениями во всех разделах                                                              |
| `forum_list_topics`         | темы раздела: закреплённые, закрытые, кто может отвечать                                                  |
| `forum_get_topic`           | посты темы по 15 штук; по умолчанию — последние, плюс опрос и кто читает тему сейчас                      |
| `forum_get_post`            | один пост по ссылке `/post/N` и где он находится в теме                                                   |
| `forum_find_users`          | игроки по началу ника                                                                                     |
| `forum_user_topics`         | темы, созданные игроком (по нику или id)                                                                  |
| `forum_get_player_card`     | карточка игрока: даты, профессия, блоки, посты и рейтинг на форуме, баны                                  |
| `forum_get_clan`            | клан: лидер, участники, место, войны и союзы                                                              |
| `forum_list_staff`          | администрация, модераторы и хелперы                                                                       |
| `forum_list_communities`    | сообщества: список, поиск по названию, открыто ли для вступления                                          |
| `forum_get_community`       | карточка сообщества: создано, темы, посты, открыт ли набор; с входом — состоите ли вы и можно ли вступить |
| `forum_community_members`   | участники сообщества: кто сейчас в игре и на каком сервере, активность                                    |
| `forum_community_blacklist` | чёрный список сообщества с причинами                                                                      |
| `forum_community_topics`    | темы раздела сообщества                                                                                   |
| `forum_list_screenshots`    | галерея скриншотов: категории, лучшие и обсуждаемые, по автору                                            |
| `forum_get_screenshot`      | скриншот: автор, рейтинг, картинка, комментарии                                                           |

С входом под своим аккаунтом добавляются:

| Инструмент                                           | Что делает                                                                                                                       |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `forum_community_sections`                           | разделы форума сообщества и какие из них только для участников                                                                   |
| `forum_community_topic`                              | посты темы сообщества                                                                                                            |
| `forum_my_community_topics`                          | свежие темы из ваших сообществ                                                                                                   |
| `forum_join_community`, `forum_leave_community`      | вступить в сообщество или выйти (ассистент спросит подтверждение)                                                                |
| `forum_create_post`                                  | ответить в теме (общей или сообщества) от вашего имени                                                                           |
| `forum_create_community_topic`                       | создать тему в разделе сообщества                                                                                                |
| `forum_list_conversations`, `forum_get_conversation` | личные сообщения: папки, непрочитанные, чтение переписки                                                                         |
| `forum_send_message`, `forum_reply_message`          | написать игроку в ЛС или ответить в переписке                                                                                    |
| `forum_get_profile`                                  | профиль игрока (или ваш): регистрация, группы, игровая статистика, клан, сообщества                                              |
| `forum_profile_section`                              | раздел профиля: баны, заморозки, предупреждения, карма, оценки, друзья, заходы в игру и на форум, достижения, скриншоты, приваты |
| `forum_zone_info`                                    | приват: владелец, место, размер, кто прописан                                                                                    |

## Настройки

Переменные окружения задаются в конфиге клиента, все необязательные.

| Переменная                      | По умолчанию                        | Что это                                    |
| ------------------------------- | ----------------------------------- | ------------------------------------------ |
| `FORUM_LOGIN`, `FORUM_PASSWORD` | —                                   | вход под своим аккаунтом                   |
| `LOG_LEVEL`                     | `info`                              | `debug` — подробные логи для отладки       |
| `FORUM_MIN_INTERVAL_MS`         | `300`                               | минимальная пауза между запросами к форуму |
| `FORUM_TIMEOUT_MS`              | `15000`                             | таймаут одного запроса к форуму            |
| `FORUM_BASE_URL`                | `https://forum.minecraft-galaxy.ru` | адрес форума                               |
