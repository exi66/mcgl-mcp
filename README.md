# mcgl-mcp

[![npm](https://img.shields.io/npm/v/mcgl-mcp)](https://www.npmjs.com/package/mcgl-mcp)
[![CI](https://github.com/exi66/mcgl-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/exi66/mcgl-mcp/actions/workflows/ci.yml)

MCP-сервер для [форума Minecraft Galaxy](https://forum.minecraft-galaxy.ru/main/). Подключается к Claude, Cursor и другим AI-ассистентам и даёт им читать форум: разделы, темы, посты, опросы.

Что можно попросить у ассистента:

- «Что нового на форуме MCGL?»
- «Перескажи последние сообщения в теме про Гран-при амфибий»
- «О чём спорят в разделе Предложения?»
- «Найди в теме 133931 рецепт крафта и объясни его»

## Установка

Нужен [Node.js](https://nodejs.org) 22 или новее. Отдельно ставить ничего не надо: клиент сам скачает и запустит сервер через `npx`.

**Claude Code:**

```bash
claude mcp add mcgl -- npx -y mcgl-mcp
```

**Claude Desktop, Cursor и другие:** добавьте в конфиг MCP-серверов (`claude_desktop_config.json`, `.cursor/mcp.json` и т.п.):

```json
{
  "mcpServers": {
    "mcgl": {
      "command": "npx",
      "args": ["-y", "mcgl-mcp"]
    }
  }
}
```

На Windows, если клиент не находит `npx`: `"command": "cmd"`, `"args": ["/c", "npx", "-y", "mcgl-mcp"]`.

### Вход под своим аккаунтом (необязательно)

Сейчас все инструменты работают и без входа. Вход понадобится для действий от вашего имени, например чтобы писать посты: это в планах. Настроить его можно уже сейчас.

```bash
claude mcp add mcgl -e FORUM_LOGIN=ник -e FORUM_PASSWORD=пароль -- npx -y mcgl-mcp
```

В JSON-конфиге то же самое задаётся через `"env": { "FORUM_LOGIN": "ник", "FORUM_PASSWORD": "пароль" }`.

Пароль хранится только в конфиге клиента на вашем компьютере и отправляется только на форум. Если войти не получилось, текст ошибки форума виден в логах MCP-сервера в клиенте. У форума есть лимит попыток входа, поэтому после неудачи сервер больше не пытается войти: исправьте пароль и перезапустите клиент.

## Инструменты

| Инструмент            | Что делает                                                                           |
| --------------------- | ------------------------------------------------------------------------------------ |
| `forum_list_sections` | разделы форума по категориям                                                         |
| `forum_latest_topics` | темы со свежими сообщениями во всех разделах                                         |
| `forum_list_topics`   | темы раздела: закреплённые, закрытые, кто может отвечать                             |
| `forum_get_topic`     | посты темы по 15 штук; по умолчанию — последние, плюс опрос и кто читает тему сейчас |
| `forum_get_post`      | один пост по ссылке `/post/N` и где он находится в теме                              |

## Настройки

Переменные окружения задаются в конфиге клиента, все необязательные.

| Переменная                      | По умолчанию                        | Что это                                    |
| ------------------------------- | ----------------------------------- | ------------------------------------------ |
| `FORUM_LOGIN`, `FORUM_PASSWORD` | —                                   | вход под своим аккаунтом                   |
| `LOG_LEVEL`                     | `info`                              | `debug` — подробные логи для отладки       |
| `FORUM_MIN_INTERVAL_MS`         | `300`                               | минимальная пауза между запросами к форуму |
| `FORUM_TIMEOUT_MS`              | `15000`                             | таймаут одного запроса к форуму            |
| `FORUM_BASE_URL`                | `https://forum.minecraft-galaxy.ru` | адрес форума                               |
